# 喵师傅 1.6.3

从 [v1.6.3 发布页](https://github.com/ZHC00813/Master-Miao/releases/tag/v1.6.3) 下载 MasterMiao-1.6.3-Setup-x64.exe 安装桌面程序。要使用 SOLIDWORKS 面右键命令，请在孔助手点击「一键部署到 SolidWorks」，重新打开 SOLIDWORKS 并启用「喵师傅孔标注」。

在零件上右键单击外圆柱侧面，选择「喵师傅孔标注」→「选中面添加为外螺纹」，选择标签并应用，保存零件。程序内置「公制外螺纹」组的 M1 至 M10 粗牙标签。可以在分组旁点击「新建组」继续扩充标签库。

在 SOLIDWORKS 2024 SP0.1 的零件副本上通过右键应用了 M1×0.25 外螺纹。通过隔离新装和从 1.6.2 覆盖升级验证，逐项核对了十个预设的分组、螺距和 RGB。
