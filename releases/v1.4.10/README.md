# 喵师傅 1.4.10 — PCB 极致轻量

喵师傅 Master Miao 1.4.10 更新说明

新增：PCB 极致轻量
勾选“极致轻量：接口也参与排名，仅保留前 N 个轮廓”。所有非板体元件（包括接口）按体积统一排序，N可编辑，默认10。点击“应用规则到清单”查看结果。
前N个元件全部使用圆柱或方形轮廓，其余元件明确显示“不输出此元件”。板体保留原轮廓和安装孔；原始文件不变。
取消极致轻量后恢复普通模式：重要接口可独立保留原形，其他元件按体积保留前N个，其余简化。
可另勾选微小连接生成单实体；无法在0.2mm范围内连接时停止，不强行填满间隙。
单实体输出为STEP和SLDPRT，并检查STEP再导入、原生零件保存重开及保留部位采样。普通多实体输出完成几何和STEP回读检查。

本次样本验证
前10个元件中包含4个接口。轮廓模式为11实体、617面、2177428字节；进一步合并后为1实体、529面、918058字节，SolidWorks原生几何错误0项，保存重开通过。
验证覆盖N=0、1、10、超出元件数量、恢复普通模式以及错误计划拒绝。结果仅代表已测试样本，不保证所有PCB模型。

数据保留
升级不会替换个人孔标签、颜色编码库、API Key或已完成孔标注的模型。安装包不包含用户项目和个人配置。

此版本沿用1.4.6核心；新增模块源码位于modules/PcbLightweight。GitHub Actions仅校验并发布本地验证的安装包，不运行SolidWorks。
