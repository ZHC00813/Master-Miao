# 喵师傅 1.4.8 — Logo 显示修复

修复左上角品牌图案、空列表图案及其他通过 Icon.ToBitmap 显示 Logo 的位置出现彩色噪点的问题。

原 Logo 图案不变。图标各尺寸改用带透明通道和掩码的 32 位 DIB，避免旧版 .NET Framework 对 PNG 图标帧转换异常。主程序内嵌图标、安装程序图标、安装目录图标使用同一修复资源。

升级安装会覆盖旧的 MasterMiao.ico，防止旧版图标被保留下来。已有窗口需要关闭重开才会加载新图标。

继承 1.4.7 的 PCB 模型轻量化功能。本次不更改孔助手插件、孔标签、颜色编码库或 API 设置；不包含用户模型和数据。原核心保持 1.4.6，部分原模块内仍显示其核心版本文字。

已验证 .NET Framework 的 16、32、48、64、128 像素图标读取，修复后界面左上角和空列表图案显示正常，透明角没有白边。安装包按下附 SHA256 校验。

运行 MasterMiao-1.4.8-Setup-x64.exe 升级。完整程序、运行环境和新增模块均包含在安装包中；模块源码位于 modules/PcbLightweight，图标生成修复位于 tools/BuildIcon.ps1。
