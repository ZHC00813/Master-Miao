# 喵师傅 1.6.1 — 修复多实体读取误开窗口

2026-11-24

拖入零件后，1.6.0 启动外壳没有转交后台任务参数，导致读取进程打开新的主界面，原任务无法收到结果。1.6.1 恢复命令行任务分流，在当前进程调用原核心入口，保留工作目录、依赖解析、STA、进度输出和退出码。错误的 worker 参数直接退出，无参数启动仍显示主界面。

## 验证

- 真实零件副本读取成功：16 个实体、48 张三视图预览；后台读取进程没有主窗口，最终返回码为 0。
- 缺失请求文件返回失败结果和退出码 1；错误 worker 参数返回 64，不弹主界面。
- 已安装版本后台入口复测通过，安装完成无需重启 Windows。
- 孔标签与颜色编码库校验未变；未改写生产零件或已有孔标注。

仅修改启动外壳，其他功能沿用 1.6.0。安装包与桌面已安装测试所用版本一致。保存当前项目后退出旧窗口，再启动喵师傅使用新版。

安装包：`MasterMiao-1.6.1-Setup-x64.exe`。校验值见 `SHA256SUMS.txt`。
