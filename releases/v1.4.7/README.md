# 喵师傅 1.4.7

新增“PCB模型轻量化”，在左侧模块栏使用。可独立保留重要接口，按体积保留其他元件的前 N 个原形，并将剩余元件简化为局部长方体或圆柱占位；支持逐项修改。

板体、孔槽、位置和朝向保持。使用具名的单零件多实体 STEP，不强行融合或增加连接。原文件不覆盖，未知元件需要人工确认。

## 下载和升级

运行本目录的 `MasterMiao-1.4.7-Setup-x64.exe`，已有安装将沿用安装位置和桌面快捷方式。运行环境已附带，无需自行安装 Python。

升级不删除孔标签、颜色编码库、API 设置和项目数据，不重新注册或替换现有孔助手插件。本版本使用验证过的 1.4.6 核心和孔插件，新增独立 PCB 模块。程序入口版本为 1.4.7，部分原模块内部版本文字仍为 1.4.6。

## 验证范围

实测样件从 569 个实体、47,134 个面简化为 248 个实体、8,380 个面；保留板体、4 组重要接口及其他元件前 10 项原形，108 项简化。STEP 从约 50.8 MB 降到 37.0 MB。

SolidWorks 2024 SP0.1：最终格式成功导入、保存 SLDPRT 并两次关闭重开，始终 248 个实体、0 个曲面。标签和颜色库前后校验一致。

早期单实体/匿名装配测试曾失败，清理这些失败测试文档后发生过 SolidWorks 退出，具体根因未完全确认。最终格式在重启后的复测中未复现。不同几何内核的体积计算约有 0.19% 差异；本功能用于结构占位，不用于精确质量或制造计算。

## 源码布局

新增模块、正式启动入口和构建脚本在 `modules/PcbLightweight`。仓库根目录历史主程序源码仍为 1.4.1，不应拿它覆盖 1.4.6 核心。完整可安装程序以本次附带的已验证安装包为准；安装包包含原核心和新增模块，不包含用户标签库、API key、工程文件或恢复备份。
