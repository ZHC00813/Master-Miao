# 喵师傅 1.5.0 — 焊接体分组

新增左侧“焊接体分组”：手动新建和编辑组、零件实例多组归属、小方框编号标记、组和成员高亮、显示/隐藏、删除及右键全选/全不选/反选。

自动辅助分组以一个基准零件查找允许间隙内的直接邻近零件，支持名称排除，候选由用户勾选确认。不会沿接触链自动合并整个装配体。

小标记使用独立注解，不改变几何或孔颜色。按零件尺寸排列多个编号。分组数据单独保存，小标记需保存装配体；换路径、配置或电脑时请留意[数据保存范围与操作说明](../../modules/WeldGroups/焊接体分组说明.txt)。

多组高亮使用 SW 六种选择色，超过六组循环；共享实例保留全部组编号，但整件高亮只采用其中一组的选择色。自动建议不等于已确认焊缝，本版尚未接入按组拆分导出。

验证：SolidWorks 2024 独立合成装配体中完成多实例、共享归属、标记去重、保存重开、删除隔离、间隙筛选、原面外观保留。安装版实际点击验证了新建、加入、成员高亮、候选查询与确认、删除。安装前后用户孔标签库校验一致，孔插件和原核心二进制一致。

本安装包保留经验证的 1.4.6 Core 和 1.4.11 PCB 模块，新增源码在 `modules/WeldGroups`；根目录历史源码不代表本次完整核心。没有包含用户模型、标签库或 API 配置。

安装前保存项目并退出喵师傅。安装包不删除用户孔标签、颜色编码或加密设置。
