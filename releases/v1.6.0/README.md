# 喵师傅 1.6.0

2026-11-18：统一模块界面、PCB 双格式输出、焊接体多组标牌。

## 更新

- 孔助手、自动工程图、AI 图纸建模、PCB 轻量化和焊接体分组沿用多实体导出的浅灰底、白色内容区、红色主按钮与浅红选中行。未启用的主按钮使用浅灰色。实际标签色块保持原色。
- PCB 可分别选择 STP、SLDPRT 或两者；保留拖入模型、极致轻量和微小连接单实体选项。运行时显示进度活动条，完成后显示生成文件和目录。
- 多实体原生输出先重建并验证几何，再发布所选文件；校验失败不发布不完整结果，同名文件不覆盖。
- 同一零件的多个焊接标牌集中排列，整组含间距不超过最大外表面面积的 25%，单张不超过 10×10mm，并按体积及可用空间统一缩小。
- 标牌完整放在同一个最大平面内，避开孔和相邻面的投影，禁止跨面。最大表面为曲面或无安全放置空间时提示并保留旧标牌，不强行贴图。
- 标牌的数字、填充色可修改，支持组别显示隐藏、多组高亮、保存重开。
- 所选焊接组输出独立 SLDASM，可选 STEP；继续引用源零件，不生成零件副本。保留位置、实例和配置，不复制配合关系。STEP 不携带标牌贴图。

## 验证范围

- 独立三实例装配体：八组共享标牌、单面范围、面积与尺寸、颜色保留、显示隐藏、保存重开、组移除及源引用导出通过。
- 复杂 PCB：11 个实体、99 个保留检查点、STEP 回读和 SLDPRT 保存重开通过；最终界面双格式导出显示完成与目录。
- 文件发布逻辑：STP 单选、SLDPRT 单选、双选、未选格式拒绝、已有文件保护、部分失败回滚通过。
- 五个功能页面已进行实际切换与布局检查。此次没有重新验证所有历史功能，也没有发送生产图纸到 AI 服务。

## 安装与数据

安装程序更新应用目录，不删除用户配置目录。孔标签库、颜色编码及模型内孔标注不进行迁移、清空或重写；孔助手和多实体导出核心继续使用已经验证的组件。标题 1.6.0 是外壳版本，历史核心部分状态栏仍可能显示 1.4.6。

安装前请保存正在编辑的项目。焊接标牌需要在 SolidWorks 中保存装配体；分组资料独立自动保存。不要删除导出装配体附带的焊接组数据目录。
