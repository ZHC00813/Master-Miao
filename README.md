Master Miao 是 Windows 上的 SolidWorks 多实体零件整理工具：读取一个或多个 SLDPRT，查看三视图、重命名、按文件夹标签分类，再导出独立零件、可选 STEP、原位装配体和带缩略图的 Excel 清单。红白界面沿用猫咪扳手品牌图标。

V1.2.6 是基于 V1.2.5 的稳定性与数据安全更新。实际测试结果见 [VALIDATION.md](VALIDATION.md)，逐条需求状态见 [ACCEPTANCE_CHECKLIST.md](ACCEPTANCE_CHECKLIST.md)。历史版本的桌面成功记录不代表本版本已完成相同验收。

当前交付为测试候选版。R2 已在真实 SolidWorks 2024 中读取独立副本的 94 个实体；定位后的完整桌面链路因测试环境活动对象连接失败而未完成，完整 STEP/装配体导出仍待验收。具体修复与证据见 [R2_FIX_VALIDATION.md](R2_FIX_VALIDATION.md)。请先使用工程副本测试，不要直接作为生产交付依据。

## 环境与开始使用

- Windows 10/11 x64、.NET Framework 4.x、本机已安装并可正常使用的 SolidWorks。当前测试环境为 SolidWorks 2024，其他版本未全面验收。
- 程序和 SolidWorks 必须处于相同的 Windows 权限级别；不要为解决连接问题随意修改系统或宏安全设置。
- 解压完整包后运行 `MasterMiao.exe`，选择中文或 English。
- 拖入/选择一个或多个 SLDPRT。读取前确认 SolidWorks 使用提示；自动启动失败时可手动打开后重试，主页面也有打开按钮。
- 读取、定位、导出均不保存用户源文件。读取时若 SolidWorks 因自动重建标记文档待保存，程序允许先查看和分类并给出警告；正式导出仍拒绝未保存修改、配置不一致或源文件内容变化。
- 读取成功后源文件留在 SolidWorks，方便定位；转交给用户的会话不会在后续任务中被当作可强制回收的后台进程。

## 整理流程

1. 列表支持三张视图、紧凑显示、缩放、多选、名称搜索，以及未分类/失败/疑似重复筛选。筛选只改变可见项，界面分别说明当前显示范围与整个项目的导出勾选范围。
2. 单击名称进入独立编辑框。输入法选字和自动保存不会主动提交草稿，Enter 只用于输入法确认且不会退出；使用“命名完毕”或离开单元格提交，Esc 取消。逐项模式把名称、分类和选择作为一次操作保存，再进入下一项或返回列表。
3. 标签就是目录节点。可拖动目录块修改父子关系；同级重名、循环关系会被拒绝。删除父节点时保留并提升子节点。支持分类模板、批量命名预览和有限步撤销。
4. 勾选“相同几何仅导出一件”后，匹配指纹的实体立即在列表折叠为一项；取消勾选恢复全部实体，不删除已有记录。组内改名、分类和选择统一。可在重复审查中排除需要单独生产的成员。导出前验证每个被折叠成员的真实几何，不一致时停止该组并显示原因；报表保留数量及全部来源。不同材料、表面处理仍需自行区分。
5. “在 SW 中定位”直接匹配已打开源文件中的实体，不再读取磁盘摘要，也不因待保存标志而拒绝高亮；配置不符或实体身份不明确时仍提示重新读取。正式导出继续严格检查源文件与几何身份。
6. 几何相同不等于生产零件相同。材料、加工要求、表面处理和自定义属性不在本次判定范围内，合并前必须自行核对。原位装配体与“重复组只导出一件”互斥，以免丢失实例位置。
7. 选择输出根目录和格式。设置立即写入项目；开始任务时复制为独立快照，进行中不能修改任务输入。结束后显示耗时、结果数量和失败原因。

## 导出与校验

- SLDPRT：保存到暂存区，重新打开，检查单实体、体积、面积、精确范围及几何一致性，再归位。
- STEP：依赖 SLDPRT，通过随包编译宏执行装配体批量保存。宏恢复原选项后，程序不仅检查 STEP 文件头，还重新导入检查实体数、几何和原位关系。无法验证时按失败处理，不仅凭文件存在宣告成功。
- 原位装配体：使用本次通过验证的零件；检查实际引用、组件数、固定状态与变换。跳过但未验证的旧文件不会加入新的装配体。
- 重名：支持跳过、全局自动编号、覆盖前备份；编号规划同时考虑两套根目录、装配体和本批其他名称。提交采用同目录临时文件和原子替换，不先删除已有有效文件。
- 部分失败：保留已通过校验的 SLDPRT；逐件检查点记录成功、失败、跳过、取消、未执行。可以仅重试失败项，重试仍检查源身份和依赖，旧文件不会自动变成可信输入。
- 取消：同步 SolidWorks 调用不能保证立即中断；界面明确显示等待安全边界，不强杀用户会话。没有进度时显示等待诊断。

STEP 存放可以选同目录，或独立镜像分类树：

```text
输出根目录/
  零件源文件/分类/零件.SLDPRT
  STEP生产文件/分类/零件.STEP
  导出清单.xlsx
```

报表包含三张等比例缩略图、实际名称/计划名称、数量、所有来源、实际路径、逐格式状态和验证结果；冻结表头、启用筛选，支持中英文。缺失预览有文字占位，不伪造成功图片。

## 保存、迁移与恢复

工作项目保存为 JSON 加 `Previews` 文件夹。新预览使用不可变内容摘要文件名，项目内保存相对路径；移动整个项目文件夹仍能找到图片。兼容旧 schema 2 的预览路径迁移。

原始 CAD 文件不会被复制进工作项目。重新绑定源文件须通过内容 SHA-256 检查；内容变更要求重新读取。自动保存只保存已提交模型，后台写入带独占锁、原子替换与 `.bak` 备份。失败会提示并保留未保存状态。恢复记录按程序实例/项目隔离，避免一个窗口清理另一个窗口的数据。

## 开发与构建

```powershell
.\build.ps1
# 或指定本机 SolidWorks API 程序集目录
.\build.ps1 -SolidWorksApiPath 'D:\SOLIDWORKS\api\redist'
```

也可设置环境变量 `MASTER_MIAO_SW_API`。构建不安装全局依赖、不写注册表；输出在 `build/`。发行时必须同时包含 EXE、配置、编译宏和 SolidWorks 互操作程序集。代码保持 WinForms + 少量职责明确的辅助类，不引入框架堆叠。

详细开发说明为中英双语，见 [架构](ARCHITECTURE.md)、[变更](V1.2.6_CHANGES.md)、[V1.2.5兼容性审计](V1.2.5_COMPATIBILITY_AUDIT.md)、[验证](VALIDATION.md)。测试源码在 `tests/`；本机 CAD、项目、缓存及私人路径记录不随公开源码/发行包分发。

## 已知边界

本程序不是独立 CAD 内核，不能在未安装 SolidWorks 的电脑上导出几何。不自动安装 SolidWorks、不更改授权、不修改系统配置。人工重复组确认不替代工程审查；不同材料或制造规范需要分别管理。暂不加入 DXF、BOM、材料识别或在线协作，优先把现有流程做稳定。
