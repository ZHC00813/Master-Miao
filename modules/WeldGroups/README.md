# 焊接体分组

独立工作区模块，使用已验证的 1.4.6 Core 接口，不改动孔标注模块。整包构建入口是 `../PcbLightweight/build-release.ps1`。

`WeldStore.cs` 保存按装配体路径和配置隔离的分组数据；`WeldBridge.cs` 负责零件实例持久引用、独立命名注解、选择高亮和距离候选；`WeldModule.cs` 提供界面。详细操作及限制见 `焊接体分组说明.txt`。

## 已验证

在 SolidWorks 2024 的独立合成装配体中插入同一小零件的三个实例，以两个组共享中间实例进行验证：

- 实例身份分离、组内去重、多组共享。
- 四个小方框编号，保存并重新打开后引用有效且不重复。
- 两组选择高亮，原面外观值逐项相同。
- 从第一组移出共享成员、删除第一组后，第二组及其两个标记仍保留。
- 0.1 mm 间隙：0.2 mm 阈值命中，0.01 mm 阈值排除；名称排除生效，且不沿邻近链合并第三个零件。
- 安装版实际点击：连接、新建、加入、成员高亮、查询候选、勾选加入及删除测试组。
- 用户孔标签库升级前后 SHA-256 一致。用户模型和标签数据未加入本仓库。

## 已知边界

高亮使用六种 SolidWorks 选择颜色，超过六组循环；自定义颜色用于小编号。共享实例不能同时显示多种整件选中颜色，以多个编号表达全部归属。选择色不会写入模型外观。

自动分组是待确认的直接邻近候选，不推断真实焊缝。未解析和压缩零件不参与。大装配体的扫描在当前线程执行，暂不支持中途取消。

分组数据位于当前用户 LocalAppData，与装配路径和配置绑定；搬移装配体、另存或换电脑时需另行迁移。小标记本身随装配体保存。移动零件后需刷新标记。本版未包含后续按组拆分导出。
