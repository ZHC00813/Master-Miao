# 焊接体分组 1.6.0

基于已验证的 1.4.6 Core，不修改孔标注模块。整包构建入口为 `../PcbLightweight/build-release.ps1`。

- `WeldStore.cs`：按装配体路径和配置保存分组，兼容旧组数据与自定义数字。
- `WeldBridge.cs`：零件实例持久引用、独立标记显示、高亮、临时隐藏及邻近建议。
- `WeldBadge.cs`：透明底、黑框、可改填充色和数字的标牌图像及遮罩。
- `WeldDecals.cs`：装配体实例贴图，只选择最大外表面（须为平面），检查标牌区域避开孔洞；旧注解迁移。
- `WeldExport.cs`：每组导出引用源零件的独立 SLDASM，可选 STEP；不生成零件副本。
- `WeldModule.cs`：分组、标牌编辑、显示控制与导出界面。

## 后台验证

在独立 SolidWorks 2024 合成装配体中，以同一零件的三个实例、两个共享组验证，包含旋转实例：

- 实例去重与共享归属、四张标牌、原面颜色保持。
- 独立隐藏、全部隐藏/显示、保存重开及刷新后状态保留。
- 数字与填充色修改不改变成员引用、不累积旧标牌。
- 旧注解迁移、共享成员移出及删除组互不影响。
- 两组 SLDASM 与 STEP 导出，重开校验源文件引用、实例数、位置、配置及标牌数量。
- 不导出 STEP 的分支及同名输出隔离；导出目录没有 SLDPRT 副本。
- 源零件字节及保存状态保持，导出后返回原装配体。
- 透明外围、遮罩、填充色、旧标签回退、数字校验通过。

八组共享标牌已通过实际外观、单组隐藏、多组高亮及保存重开验证。正式构建再次通过完整独立装配体回归；详见 releases/v1.6.0。

## 边界

贴图附着于具体装配体实例，不向源零件写入贴图或更改几何。当前自动定位要求最大外表面是平面且有足够安全空间，标签不得跨面；不能安全放置时明确提示。移动零件后需刷新标牌，并保存装配体。

高亮使用六种 SolidWorks 选择色，超过六组循环；共享实例的全部归属由多个标牌表达。自动建议仅找与基准零件直接邻近的候选，需要用户确认。

导出装配体保持固定位置，不复制原配合。源零件必须保留原路径。STEP 只输出几何，不含贴图。导出文件夹附带分组数据及贴图资源；分组数据与装配体路径、配置关联，改变路径仍需重新关联。
